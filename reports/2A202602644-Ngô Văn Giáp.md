## Quyết định kỹ thuật quan trọng

Mô tả tối đa hai quyết định mà bạn trực tiếp tham gia:

1. **Quyết định:** Cấu hình đường dẫn cache `CRAWL4_AI_BASE_DIRECTORY` trỏ về thư mục nội bộ `data/_crawl4ai` trong dự án thay vì thư mục cá nhân người dùng (`~/.crawl4ai`).  
   **Lý do/evidence:** Khi thực thi script crawl trong môi trường CI/CD, máy chủ hoặc container phân quyền hạn chế, việc truy cập User Home Directory mặc định thường gây ra lỗi nạp browser profile hoặc rò rỉ state giữa các đợt chạy.  
   **Trade-off:** Tăng dung lượng lưu trữ cục bộ của dự án (cần đưa `_crawl4ai` vào `.gitignore`), đổi lại đảm bảo 100% tính độc lập (isolation) và khả năng tái lập pipeline crawler mà không phụ thuộc vào cấu hình máy cá nhân.

2. **Quyết định:** Chuẩn hóa dữ liệu đa nguồn (PDF & JSON) về định dạng Markdown đồng nhất và bọc bổ sung Metadata Header trước khi bàn giao cho pipeline Chunking/Indexing.  
   **Lý do/evidence:** Tài liệu pháp lý PDF và tin tức web có cấu trúc dữ liệu thô khác nhau. Việc gắn sẵn Header metadata (`# Title`, `**Source:**`, `**Crawled:**`) ngay trong file `.md` giúp quá trình Chunking ở Task 4 kế thừa trực tiếp metadata nguồn, giúp LLM dễ dàng trích xuất Citation chính xác khi trả lời câu hỏi.  
   **Trade-off:** Phát sinh bước lưu trữ trung gian `data/standardized/` làm tăng khối lượng I/O file, nhưng giúp toàn bộ module phía sau (Dense Search, BM25, Hybrid RRF) hoạt động nhất quán trên một giao diện dữ liệu duy nhất.

## Kiểm thử và kết quả

- **Test hoặc query tôi đã dùng:**  
  - Chạy `python -m src.task1_collect_legal_docs` tạo cấu trúc thư mục landing legal.
  - Chạy `python -m src.task2_crawl_news` crawl thành công 5/5 bài báo về du lịch Bắc Giang (Suối Mỡ, Tây Yên Tử, Vải thiều Lục Ngạn, v.v.), sinh ra 5 file JSON chuẩn schema trong `data/landing/news/`.
  - Chạy `python -m src.task3_convert_markdown` chuyển đổi thành công 3 file PDF lớn thành Markdown (`.md` từ 114KB - 271KB) và 5 file tin tức `.md` có gắn Metadata Header.
  - Chạy kiểm tra validate file không bị rỗng (`content.strip() != ""`).
- **Kết quả trước/sau nếu có:**  
  - *Trước:* Dữ liệu nằm ở dạng PDF thô và dữ liệu web phân tán, chưa thể đưa vào vector index.
  - *Sau:* Bộ dữ liệu 3 tài liệu pháp lý PDF và 5 bài tin tức đã được thu thập, chuẩn hóa sạch sẽ sang Markdown, sẵn sàng 100% cho bước Chunking và Indexing (Task 4).
- **Lỗi đã phát hiện và cách xử lý:**  
  - *Lỗi Crawl4AI trả về object thay vì string:* Trong các phiên bản Crawl4AI khác nhau, `result.markdown` có thể là `MarkdownGenerationResult`. Đã viết hàm `_article_from_result()` để linh hoạt trích xuất `fit_markdown` hoặc `raw_markdown` mà không bị crash script.
  - *Lỗi file rỗng sau convert:* Bổ sung log warning và câu lệnh kiểm tra `content.strip()` để tránh ghi ra các file `.md` rỗng gây hỏng dữ liệu retriever.
